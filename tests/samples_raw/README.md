# Fichiers RAW de test

`synthetique.dng` est un petit DNG généré artificiellement (pour la CI).

Pour tester avec de **vraies photos iPhone (DNG / ProRAW, HEIC, MOV)**, copie-les ici :
elles seront automatiquement incluses dans `pytest`. Elles sont ignorées par git
(voir `.gitignore`) pour ne jamais publier de photos personnelles.
