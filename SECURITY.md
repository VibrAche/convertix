# Sécurité

## Signaler une faille

Si tu trouves une faille de sécurité dans Convertix (par exemple un fichier piégé qui ferait exécuter du code),
**ne l'ouvre pas en issue publique**. Signale-la en privé :

👉 onglet **Security** du dépôt → **Report a vulnerability**

Décris le problème, comment le reproduire et la version concernée. Tu recevras une réponse dès que possible,
et la correction sera publiée dans une nouvelle version.

## Versions suivies

Seule la [dernière version](https://github.com/VibrAche/convertix/releases/latest) reçoit des corrections :
mets Convertix à jour avant de signaler un problème.

## Ce que fait Convertix

- Les conversions se font **entièrement sur ton ordinateur**, sans rien envoyer sur Internet.
- La seule connexion est la vérification des nouvelles versions auprès de GitHub (désactivable dans les Réglages).
- Aucun droit administrateur n'est demandé.
